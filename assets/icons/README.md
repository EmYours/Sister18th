Map icon sources:

- Google Maps and Waze: Simple Icons, downloaded through https://cdn.simpleicons.org/ in silver (#D5E0F5).
- Apple Maps: Apple Maps App Store artwork, app ID 915056765, retrieved through Apple's lookup endpoint https://itunes.apple.com/lookup?id=915056765.

Icons are stored locally and used only to identify links to the respective map services. Service names remain visible alongside the icons.
